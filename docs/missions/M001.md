# Mission M001

## Outcome

Deliver a deterministic, standard-library Python ReAct Agent that safely answers supported arithmetic and built-in knowledge questions through both a typed API and CLI, always returns an auditable bounded trace, and exposes explicit outcomes for required failure paths.

## Acceptance Criteria

- The public API and CLI accept a question and positive maximum-step bound, and successful arithmetic and knowledge requests return the expected answer plus an ordered trace of thoughts, tool calls, observations, and final output.
- The tool registry contains only the safe arithmetic and fixed-table knowledge tools, validates tool names and arguments, and produces explicit outcomes for unknown tools, invalid arguments, injected failures, and maximum-step exhaustion.
- The complete `python -m unittest discover -s tests -v` suite passes deterministically using only the Python standard library, with no network, user-home, or global-environment dependency.
- A documented `python -m react_agent` smoke invocation succeeds and renders the answer and numbered trace.
- A repository safety scan finds no implementation call path using `eval`, `exec`, `subprocess`, `os.system`, or shell execution.
- README documentation describes module boundaries, supported questions/tools, API and CLI usage, failure behavior, and reproducible verification commands.

## Constraints and Risks

- One end-to-end Task owns the implementation, tests, documentation, and verification evidence, so its file scope must be explicit and the developer must avoid unrelated repository changes.
- The deterministic policy recognizes only a deliberately small question grammar; unsupported questions must fail clearly rather than infer unsafe behavior.
- Exception text can expose host details if forwarded directly; the agent must return bounded error categories and sanitized messages.
- Standard library only; no external runtime service or package may be required.
